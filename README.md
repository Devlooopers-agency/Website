# devlooopers website

A responsive, light-theme multi-page website concept for devlooopers.

## Pages
- `index.html` — animated landing page with interactive 3D-style hero
- `work.html` — selected work / case-study layout
- `services.html` — services and process
- `about.html` — studio story and values
- `contact.html` — contact form prototype

## Assets
- `assets/devlooopers-logo.png` — supplied logo reference
- `assets/devlooopers-animation.gif` — supplied animation reference

## Run locally
Open `index.html` directly, or serve the folder from any local web server. The hero optionally uses Three.js CDN resources, but the page remains usable without it because the main 3D effect is CSS-based.

## Customization
Replace placeholder case-study copy/links and connect the contact form to your API, Formspree, Resend, or other email/backend service.
